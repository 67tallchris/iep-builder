# Boilerplate Snippet Library (v0.1)

`snippets.json` is the seed library for the tool's drafting engine. It was generated by
`research/scripts/build_index.py` from the 30 exemplars plus curated structural templates.

## Snippet taxonomy

| `component` | What it is | How the tool uses it |
|---|---|---|
| `PLAAFP_stem`, `PLAAFP_impact` | Opening and impact statements with `{{placeholders}}` | Fill-in suggestions in the PLAAFP editor |
| `goal_frame` | Canonical SMART goal skeleton | Goal builder; slots for condition/skill/baseline/target/measurement |
| `progress_reporting` | Reporting schedule language | Progress section autofill |
| `service_type` | Deduplicated types seen across exemplars | Service-picker menu (user still sets frequency/duration/location/provider) |
| `supplementary_aid` | Classroom-level supports | Supplementary aids pick-list |
| `accommodation` | Access accommodations | Accommodations pick-list; separate from modifications |
| `program_modification` | Changes to what is learned/demonstrated | Modifications pick-list with warning styling |
| `personnel_support` | Training/consultation/coaching supports | Personnel supports section |
| `lre_pullout` | LRE explanation template | LRE builder |
| `assessment_default`, `assessment_alternate` | Assessment participation language | Assessment section |
| `esy_considered_no`, `esy_regression` | ESY documentation patterns | ESY section |
| `special_factor_*` | AT, LEP, behavior special-factor language | Special factors prompts |
| `dyslexia_statement` | Arizona SLD compliance sentence | Auto-inserted for SLD with a reminder |
| `behavior_antecedent_stem`, `behavior_replacement_stem`, `behavior_consequence_stem`, `crisis_plan_stem` | BSP builder blocks | Behavior workspace |
| `transfer_of_rights`, `transition_placeholder` | Age-triggered content | Conditional sections |

## Known limitations

- **Duplicates:** the extracted accommodation/support lists currently contain near-duplicate
  phrasings from different exemplars (e.g., "Extended time on tests" vs. "Extended time on
  assignments and assessments"). Phase 4 should cluster/dedupe these with embeddings
  (Vectorize) or a synonym pass before exposing them as menus.
- **No district-specific language yet.** All snippets are synthesized from public documents.
  District-approved phrasing should override these in production use.
- **Not legal advice.** Every snippet must remain editable; the teacher and IEP team own the
  final language.
